☁️ Google Drive · Automatic Backup

প্রতি পরিবর্তনের ~২০ সেকেন্ড পর এবং প্রতি ৩০ মিনিটে encrypted backup যায়। সর্বশেষ ১০টি রাখা হয়। শুধু এই app-এর নিজস্ব hidden folder ব্যবহার হয়।

একবারের setup guide
  1. Google Cloud Console-এ নতুন project বানান।
  2. “Google Drive API” enable করুন।
  3. “OAuth consent screen” সেট করুন (External, নিজের email test user হিসেবে যোগ করুন)।
  4. “Credentials” → Create credentials → OAuth client ID → Web application।
  5. Authorized JavaScript origins-এ যেখানে file hosted (যেমন https://yourname.github.io বা http://localhost:8000) সেটা যোগ করুন।
  6. Client ID টি এই file-এর GOOGLE_CLIENT_ID লাইনে বসান।
Google sign-in শুধু http(s) origin-এ চলে, তাই file-টি double-click করে খুললে connect হবে না — hosting বা local server লাগবে।
